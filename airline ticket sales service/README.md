# Сервис продажи авиабилетов

## Исследуемые вопросы
* топ-10 международных направлений, по которым пользователи ищут авиабилеты из Казахстана;
* составление воронки от просмотра формы поиска билета до покупки авиабилета;
* А/Б-тест, в рамках которого в тестовой ветке добавили подпись о количестве оставшихся билетов;
* выбор наиболее перспективной функции в приложении (карта цен с самыми дешевыми билетами, группировка прямых рейсов на странице результатов, подписка на цены билетов на дату);
* анализ изменения поисковой выдачи при корректировке цен одной авиакомпании.
